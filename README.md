# CustomHydration Development Platform

A modern, responsive development platform for CustomHydration with integrated WebContainer support and glassmorphism design.

## 🚀 Features

### Multi-Device Optimization
- **📱 Mobile (320px+)**: Touch-optimized interface with collapsible navigation
- **📱 Tablet (768px+)**: Enhanced touch interactions and optimized layouts
- **💻 Laptop (1024px+)**: Full desktop experience with hover effects
- **📺 TV (1440px+)**: Large screen optimization with enhanced focus states

### WebContainer Integration
- **Real Terminal**: Integrated bash terminal with full shell capabilities
- **File System**: Real file system operations through WebContainer API
- **Live Development**: Hot reload and live preview capabilities
- **Package Management**: Full npm/node.js support

### Modern UI/UX
- **Glassmorphism Design**: Beautiful glass-effect components with backdrop blur
- **Responsive Grid**: CSS Grid and Flexbox for perfect layouts
- **Smooth Animations**: 60fps animations and transitions
- **Clean Typography**: Inter font family for modern readability

## 🛠️ Development

### Quick Start
```bash
# Install dependencies
npm install

# Start development server with WebContainer
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Project Structure
```
├── src/
│   ├── styles/
│   │   └── main.css          # Main stylesheet with responsive design
│   └── main.js               # WebContainer integration and platform logic
├── backup/                   # Original HTML files (preserved)
├── index.html               # Modern landing page
├── package.json             # Dependencies and scripts
├── vite.config.js          # Vite configuration
└── README.md               # This file
```

### Key Technologies
- **Vite**: Fast build tool and development server
- **WebContainer API**: Real container environment in the browser
- **XTerm.js**: Full-featured terminal emulator
- **CSS Grid/Flexbox**: Modern responsive layouts
- **ES6 Modules**: Modern JavaScript architecture
